# Reflection

## Practical Title
TikTok REST API Design and Implementation

---

## Introduction

This practical focused on designing and implementing a RESTful API for a TikTok-style application using Node.js and Express.js. The practical involved creating backend routes, controllers, and data handling for resources such as videos, users, and comments.

The task helped in understanding how backend systems manage requests and communicate with frontend applications through APIs.

---

## What I Learned

During this practical, I learned the fundamentals of RESTful API development and backend application structure. I gained practical experience working with Express.js and learned how APIs are organized using routes and controllers.

Some important concepts learned include:

- RESTful API principles
- CRUD operations
- Express.js server setup
- Route handling
- Controllers and middleware
- HTTP methods and status codes
- Request and response handling
- Environment variable configuration
- API testing using Postman and curl

I also learned how different API endpoints are connected to specific resources such as users, videos, and comments.

---

## Challenges Faced

One of the main challenges during this practical was understanding how routes and controllers work together in Express.js. At first, managing multiple endpoints and organizing the backend structure was confusing.

Another challenge was implementing CRUD operations correctly and making sure the API returned the correct responses for different requests. Understanding how parameters such as `:id` worked in routes also required practice.

Testing the APIs and debugging server errors was sometimes difficult because small mistakes in routes or controllers could stop the server from working properly.

---

## How I Solved the Challenges

To solve these challenges, I carefully followed the practical steps and tested each endpoint one at a time. Using Postman and curl commands helped me verify whether requests and responses were working correctly.

I also organized the project into separate folders such as:
- controllers
- routes
- models
- middleware

This made the project easier to manage and understand.

Reading Express.js documentation and checking console errors also helped identify mistakes more quickly during debugging.

---

## Skills Improved

This practical improved my skills in:

- Backend development
- Express.js programming
- REST API creation
- Debugging and testing
- Project organization
- Handling HTTP requests and responses
- Writing cleaner and more structured code

It also improved my understanding of how frontend and backend systems communicate using APIs.

---

## Overall Experience

Overall, this practical was very useful because it provided hands-on experience in backend development. It helped me understand how REST APIs are built and how applications handle data through endpoints.

The practical also improved my confidence in working with Node.js and Express.js. Seeing the API successfully respond to requests made the learning process more interesting and rewarding.

This experience gave me a better understanding of modern web application architecture and backend communication.

---

## Conclusion

In conclusion, this practical successfully demonstrated the process of designing and implementing a RESTful API using Express.js. The practical improved my understanding of backend development concepts, API routing, and CRUD operations.

It also strengthened my problem-solving and debugging skills while providing valuable experience in developing server-side applications for modern web systems.
