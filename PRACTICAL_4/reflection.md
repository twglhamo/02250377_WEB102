# Reflection on Practical 4: Connecting TikTok Frontend to Backend

## Introduction
This practical provided practical experience in connecting a frontend application built with Next.js to a backend server developed using Express.js. The implementation focused on authentication, API integration, video management, and social interaction features similar to a real-world TikTok application.

---

## What I Learned
Through this practical, I learned how frontend and backend systems communicate using APIs. I understood how Axios is used to send requests and receive responses from backend services.

I also learned how JWT-based authentication works and how authentication tokens are stored and managed securely within a web application. Using React Context API helped me understand how global authentication state can be shared across multiple components.

Another important learning experience was implementing social media features such as following users, personalized feeds, and video interactions. This helped me understand how modern applications manage user engagement and dynamic content.

---

## Skills Gained
During this practical, I gained practical experience in:
- Connecting frontend and backend applications
- Configuring API requests using Axios
- Implementing JWT authentication
- Managing authentication state with React Context API
- Creating reusable UI components
- Handling video-related interactions
- Implementing follow and unfollow functionality
- Creating personalized feeds
- Managing protected routes and user sessions

---

## Challenges Faced
One challenge I faced was understanding how authentication tokens are passed between the frontend and backend. Initially, handling authorization headers and maintaining login sessions was confusing.

Another challenge was integrating multiple frontend components with backend APIs while managing loading states and handling errors properly. However, after testing and debugging the application step by step, I was able to understand the complete workflow clearly.

I also faced some difficulties while implementing personalized feeds and dynamic profile pages because they required proper routing and data handling.

---

## Conclusion
Overall, this practical was very useful in improving my understanding of full-stack web development. I successfully connected the frontend and backend systems and implemented important features such as authentication, video interactions, and social networking functionality.

The practical provided valuable experience in building modern web applications and strengthened my confidence in working with real-world frontend and backend integration.
