# Social Media RESTful API

This project is a RESTful API built using Node.js and Express.js for a social media platform similar to Instagram. The API supports resources such as users, posts, comments, likes, and followers. It demonstrates proper REST API design principles, HTTP methods, status codes, content negotiation, middleware handling, and API documentation.

## Objectives

- Design RESTful API endpoints
- Implement CRUD operations using Express.js
- Use proper HTTP methods and status codes
- Configure middleware for request and response handling
- Implement content negotiation using MIME types
- Create API documentation

---

## Technologies Used

- Node.js
- Express.js
- Morgan
- CORS
- Helmet
- Nodemon
